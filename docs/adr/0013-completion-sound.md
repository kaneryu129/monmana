# ADR-0013: 終了音は Web Audio API で合成する

- **ステータス**: Accepted
- **日付**: 2026-08-16
- **関連**: ADR-0001, ADR-0007
- **関連 Issue**: #26, #27

## コンテキスト

仕様書 6 章は「25 分経過時には、穏やかな終了音と軽いバイブレーションを行う」と定めている。

ADR-0001 でバイブレーションを任意機能に格下げした（iOS Safari が
`navigator.vibrate()` 非対応のため）。その結果、**音が完了通知の主役**になった。
仕様書 14 章の完成条件「終了時に音またはバイブレーションで知らせる」を
実質的に音だけで満たすことになる。

音源をどう用意するかを決める必要がある。

## 決定

**Web Audio API で合成する。音声ファイルを持たない。**

正弦波を 2 音重ね、ゆっくり減衰させた鐘のような音にする。

## 検討した選択肢

### 案 A: Web Audio API で合成 — 採用

- 利点:
  - **ライセンスの問題が一切ない。** 「完全無料」制約（ADR-0001）に対して、
    素材の利用条件を検討する余地すら残らない
  - 配信するファイルが増えない。オフライン動作（#40）でも音源の取得を考えなくてよい
  - 音色・長さ・音量を細かく調整できる。仕様書 13 章の「静か」に合わせ込める
- 欠点:
  - 生楽器のような複雑な音は作れない
  - 音作りをコードで行うため、聴かずに調整できない
- 採用理由: 求めているのは「穏やかな終了音」であって、凝った音ではない。
  制約とリスクが最も少ない

### 案 B: フリー素材の音声ファイルを使う

- 利点: 質のよい音をすぐ用意できる
- 欠点:
  - **ライセンスの確認と追跡が必要になる。** 商用可否、クレジット表記の要否、
    再配布の可否を確認し、それを維持しなければならない
  - 素材の配布が終了した場合に差し替えが必要になる
  - バンドルに数十 KB〜数百 KB が加わる
- 却下理由: 「完全無料」の制約下で、条件が変わりうる外部素材に依存したくない

### 案 C: 自分で録音する

- 却下理由: 録音環境が要る。合成で足りる要件に対して過剰

## iOS の自動再生制限への対処

**これが実装上の最重要点である。**

iOS Safari では、ユーザー操作を伴わない音声再生がブロックされる。
25 分後に鳴らそうとしても、その時点ではユーザー操作がない。

対策として、**「25分、勉強を始める」のタップ時に AudioContext を作成し、
無音を 1 回再生して unlock する。** 一度 unlock すれば、
同じ AudioContext からは後で音を出せる。

タイマー開始は必ずユーザーのタップから始まるため、この手当てが成立する。

## 音の設定の保存先

音のオン / オフは **localStorage に保存する。** IndexedDB は使わない。

ADR-0002 で IndexedDB を選んだのは学習記録のためであり、
これは記録ではなく表示設定である。失われても学習の積み重ねは損なわれない。
同期的に読めるほうが、初回描画で設定を反映しやすい。

## 結果と影響

### 良い影響

- ライセンスと配布に関する懸念が発生しない
- 音源ファイルがないため、オフライン対応（#40）で考えることが減る

### 受け入れるトレードオフ

- 音作りをコードで行うため、**実際に聴いて調整する工程が必要**になる。
  エージェントは音を聴けないため、最終的な良し悪しは開発者の判断に委ねる

### 残るリスクと緩和策

**リスク: 画面ロック中・タブ離脱中に音が鳴らない可能性**

ADR-0001 のリスク 3 に記載のとおり。iOS では画面ロック中に
音声再生が停止されることがある。unlock 済みでも保証はされない。

緩和策:
- **画面に戻った時点で完了を検出し、その場で表示を切り替える。**
  音が鳴らなくても、開いたときに完了が分かる状態にしておく（#23 で実装済み）
- 将来的には、ホーム画面追加済み PWA で使える Notification API
  （iOS 16.4+）を検討する。ただし MVP 対象外

**この挙動は iPhone の実機でしか確認できない**（ADR-0007）。
自動テストの対象外とし、実機確認を必須とする。

## バイブレーションについて（#27）

ADR-0001 の決定に従い、任意機能として実装する。

- `navigator.vibrate` があれば軽く振動させる
- **無い環境では何もしない。** エラーも警告も出さない
- 音のオン / オフ設定とは独立させる。振動は音ではないため

## 備考

音色が「穏やか」と感じられない場合は、`src/ui/sound.ts` の
周波数・長さ・減衰を調整する。合成であるため、素材を探し直す必要はない。
