# ADR-0008: モンステラの画風は手描き風とする

- **ステータス**: Accepted
- **日付**: 2026-08-15
- **関連**: ADR-0004
- **関連 Issue**: #51, #32〜#37

## コンテキスト

モンステラはこのサービスの中心であり、全 11 段階の見た目を作る必要がある。
画風を決めないまま実装に入ると作り直しのコストが大きいため、
実装（#32〜#37）の前に確定させることにした。

仕様書 13 章が定める世界観は「静か / やさしい / 清潔感がある / 余白が多い」。
配色は白・淡いベージュ基調、深い緑がアクセント。

開発者から追加の指定があった。

- **葉は緑、斑は白**
- 参考画像として、筆の質感がある鉢植えモンステラの絵が提示された

## 決定

**手描き風（案 C）を採用する。**

輪郭をわずかにずらした層を重ね、刷りのにじみを表現する。
均一な面や線ではなく、わずかな不均一さによって温かみを出す。

## 検討した選択肢

3 案を実際に描き、Lv.1 / Lv.5 / Lv.10 を並べて比較した。
図形データは 3 案で共通とし、塗りと線の扱いだけを変えることで、
形の違いが混ざらないようにした。

### 案 A: フラット / ミニマル

- 利点: 小さくしても形が潰れない。11 段階の作り分けが最も破綻しにくい
- 欠点: 整いすぎて素っ気なく映る。愛着が湧きにくい
- 却下理由: 毎日眺めて育てる対象としては、温度が足りない

### 案 B: 線画

- 利点: 余白がそのまま画の一部になり、仕様書 13 章の「静か・清潔感」に最も忠実
- 欠点: **白い斑を線だけでは表現できない**
- 却下理由: 仕様書 10 章で Lv.10 の白い斑は MVP のクライマックスと位置づけられている。
  その見せ場が構造的に弱くなる画風は採用できない

### 案 C: 手描き風 — 採用

- 利点:
  - 三案で最も温かく、**毎日眺める相手としての愛着**が湧きやすい
  - 提示された参考画像に最も近い
  - 白斑を面で置けるため、Lv.10 の見せ場が最も強く出る
- 欠点: 要素が増えるため SVG が重くなる。11 段階のにじみの一貫性管理が最も重い
- 採用理由: 開発者の選択。このサービスの価値は「積み重ねを実感し、また続けたくなること」であり、
  植物への愛着がその中核をなす。欠点はいずれも管理の問題であり、技術的に解決できる

## 結果と影響

### 良い影響

- Lv.10 の白い斑が面として置けるため、仕様書 10 章のクライマックスが最も強く表現できる
- 参考画像の方向性と一致するため、以降の作図で判断がぶれにくい

### 受け入れるトレードオフ

- **SVG の要素数が増える。** にじみのために層を重ねるため、
  フラット案と比べておよそ 2 倍の描画要素になる。
  ホーム画面のような小さい表示では、にじみが濁って見えるリスクがある。
  小さい表示ではにじみの層を省く、といった調整が必要になる可能性がある
- 11 段階すべてでにじみの位置を決める必要があり、一貫性の管理コストが最も高い

## 作図の方法についての決定

画風の選定と同時に、**作図の進め方も変更した。** これが本 ADR のもう一つの要点である。

### 背景

初版・第 2 版では、SVG のパス座標を手で打ち込んでいた。
このとき **描画結果を一度も確認していなかった**ため、以下の 2 つが同時に起きていた。

1. **色が一切適用されていなかった。**
   `<use>` で `<symbol>` を参照すると影の DOM が作られ、
   `.flat .leaf` のような子孫セレクタは**その境界を越えられない**。
   すべての塗り指定が無視され、黒いシルエットが表示されていた
2. **葉の形が制御できていなかった。**
   裂片が棘状になる、輪郭が多角形になる、基部が平らに切られる、といった破綻に気づけなかった

### 決定

- **葉の輪郭は関数で生成する。** 手打ちの座標を使わない。
  幅の分布、切れ込みの位置と角度、穴の配置をパラメータで調整できるようにする
- **描いたら必ず画像に書き出して目視する。** ヘッドレス Chrome でスクリーンショットを取り、
  確認してから次に進む
- **色と線幅は CSS カスタムプロパティで渡す。** カスタムプロパティは影の DOM へ継承されるため、
  `<use>` の境界を越えられる
- 生成スクリプトは `design/plant/src/` に置き、**HTML を直接編集しない**

この手順に変えた結果、実際に 4 回の描き直しを経て形が収束した。

## 備考

Lv.2〜4、6〜9、11 以降の作図は本 ADR の画風に従って進める（#33〜#35）。

小さい表示でにじみが濁る問題が実機で確認された場合は、
表示サイズに応じてにじみの層を省く方針を検討し、必要なら追加の ADR を起票する。
