# MVP 通し確認チェックリスト

仕様書 14 章の完成条件を、実機で最初から最後まで確認する手順（#46）。

**エージェント側では確認できない項目をここに集めている。**
ヘッドレス Chrome では IndexedDB も Service Worker も応答しないため（#17 で判明）、
音・オフライン動作・ストレージの保持は実機でしか確かめられない（ADR-0007）。

公開 URL: <https://kaneryu129.github.io/monmana/>

---

## はじめに: 記録を書き出しておく

**この確認では、レベルアップを試すために架空の学習記録を入れる。**
本物の記録が混ざるため、**先に書き出して、終わったら戻せるようにしておく。**

1. 植物ビュー（モンステラを見る）を開く
2. 下部の「記録の持ち出し」を押す
3. 「書き出す」を押して `monmana-YYYYMMDD.json` を保存する

これが #42 を用意した理由そのもの。確認の最後に「取り込む」で元に戻せる。

---

## 第 1 段階: 起動と表示（約 5 分）

ホーム画面に追加したアイコンから起動する。

- [ ] アイコンが**斑入りモンステラ**になっている
- [ ] 起動すると **Safari の枠が出ず全画面**になる
- [ ] 「ホーム画面に追加すると…」の案内が**出ていない**（追加済みと判定できている）
- [ ] 「いまは記録を保存できません」が**出ていない**（IndexedDB が動いている）
- [ ] 日付が今日になっている
- [ ] 挨拶が出ている（初回なら「はじめまして。」）
- [ ] モンステラが表示されている
- [ ] ノッチやホームバーに文字が隠れていない

### 画面を見比べる

- [ ] 「モンステラを見る」で植物ビューへ移動できる
- [ ] 植物ビューは**ホーム画面より余白が多く、静か**に見える
- [ ] 「← 戻る」でホームへ戻れる

---

## 第 2 段階: 25 分タイマー（約 25 分）

**仕様書 14 章の中核。ここが通れば MVP はほぼ成立する。**

「25分、勉強を始める」を押す。

- [ ] タイマー画面に切り替わり **25:00** から減っていく
- [ ] 履歴や統計が**表示されていない**（集中を妨げない画面になっている）
- [ ] カテゴリ（英語 / 資格 / その他）を選べる。**選ばなくても進む**
- [ ] 「音 オン」と出ている

### 先に音を確かめる（#85）

**25 分待つ前に「音を試す」を押す。** 終わりに鳴る音がその場で鳴る。

- [ ] 「音を試す」を押すと、**穏やかな音が鳴る**
- [ ] 押すと「聞こえないときは、本体の消音スイッチを…」の案内が出る
- [ ] **本体の消音スイッチを消音側にしても、まだ鳴る**

> 3 つめが要点。iOS では Web Audio の出力だけが消音スイッチで消えるため、
> 消音側で鳴らないなら ADR-0016 の対処が効いていない。

### 待っている間に確かめること

タイマーを動かしたまま、以下を試す。**戻ったときに残り時間が正確かを見る。**

- [ ] **ホームボタンでアプリを離れ、30 秒ほどしてから戻る**
      → 残り時間が実際の経過どおりになっている（止まっていない・飛んでいない）
- [ ] **画面をロックし、1 分ほどしてから解除する**
      → 残り時間が実際の経過どおりになっている
- [ ] 「一時停止」を押す → 残り時間が**止まる**
- [ ] 「再開する」を押す → 続きから進む
- [ ] 一時停止のあいだの時間が**経過に含まれていない**

> 経過時間は `Date.now()` の差分で測っている（ADR-0001 リスク 2）。
> ここがずれていると、25 分測ったつもりが実際は違う時間になる。

### 25 分経過時

- [ ] **穏やかな音が鳴る**
- [ ] （Android の場合）軽く振動する。iPhone では振動しないのが正しい
- [ ] 完了画面に切り替わる

**画面をロックした状態で 25 分を迎えた場合も試したい。**
iOS は画面ロック中に音声再生を止めることがある（ADR-0001 リスク 3）。

- [ ] ロック中に 25 分が来たとき、音が鳴るか（鳴らなくても仕様の想定内）
- [ ] 音が鳴らなくても、**開いた時点で完了画面になっている**

### 音の感じ方

音は合成している（ADR-0013）。**素材を探し直さずに調整できる。**
調整するのは `src/ui/chime.ts` の周波数・長さ・音量。

- [ ] 「穏やか」と感じるか。うるさい・素っ気ない・気づかない場合は伝えてほしい

**「音を試す」があるので、聴き直すのに 25 分待たなくてよい。**

## 第 3 段階: 完了画面と記録（約 5 分）

- [ ] 「おつかれさま！」と出ている
- [ ] 「25分の学びで、モンステラに水が届きました。」と出ている
- [ ] モンステラの**葉が少し揺れ、水滴が落ちる**
- [ ] 「今回 25分」「今日 25分」が出ている
- [ ] 「次のレベルまで あと n しずく」が出ている
- [ ] ひとことメモを入れられる。**空でも進める**

メモを入れて「ホームへ戻る」を押す。

- [ ] ホームの「今日」が **25分**になっている
- [ ] 「連続」が **1日**になっている
- [ ] 「直近の記録」に今回の記録が出ている（時刻・カテゴリつき）

### 途中終了も試す

もう一度タイマーを始め、**すぐに「終了する」**を押す。

- [ ] 完了画面に「モンステラに水が届きました」と**出ない**
      （しずくが付かないため。仕様書 10 章）
- [ ] 責める文言が出ていない
- [ ] ホームの「今日」が増えていない（0 分のため）

## 第 4 段階: レベルアップと斑（約 5 分）

Lv.10 まで本当に勉強すると **18 時間 45 分**かかる。
確認のため、手動記録で一気に進める。

「時間だけ記録する」を押す。

- [ ] 学習時間に **600** を入れると「この記録で **24** しずく たまります」と出る
- [ ] **601 以上を入れると「記録する」が押せなくなる**（打ち間違い対策）
- [ ] 0 や負の数でも押せない
- [ ] 範囲外のとき、責める文言が出ていない

600 分で記録する。

- [ ] レベルアップの演出が出る（**背景に光が差し、文字が大きい**）
- [ ] 通常の完了より**はっきり演出されている**と感じる
- [ ] 「モンステラを見る」が主ボタンになっている

**もう一度 600 分を記録する**（累計 48 しずく = Lv.10）。

- [ ] 「Lv.10 になりました！」と出る
- [ ] 「あなたのモンステラに、はじめての白い斑が現れました。」と出る
- [ ] モンステラに**白い斑**が見える
- [ ] 植物ビューで「成長 Lv.10 ／ 斑入りモンステラ」と出ている
- [ ] 「育てた葉」の枚数と、**実際に描かれている葉の数が一致している**
- [ ] 成長履歴に「Lv.10 達成」と「はじめての斑入りの葉」が並んでいる
- [ ] **葉をタップすると**「この葉は、累計○○の学びで育ちました。」と出る

## 第 5 段階: オフラインと保持（約 5 分）

**ADR-0001 / ADR-0002 で緩和策と位置づけた部分。ここが本丸。**

- [ ] **機内モードにして**アプリを起動する → 普通に開く
- [ ] 機内モードのまま 25 分タイマーを始められる
- [ ] 機内モードのまま手動記録ができる
- [ ] 機内モードを解除する

アプリを完全に終了して開き直す（アプリスイッチャーから上にスワイプ）。

- [ ] **記録が残っている**（今日の学習時間・連続日数・累計・レベル）
- [ ] モンステラの見た目が保たれている
- [ ] 成長履歴が残っている

---

## 後日: 保持の本当の確認

**iOS は 7 日間サイトを操作しないとストレージを削除する。**
ホーム画面に追加した PWA はこの削除の対象外になる（ADR-0001 リスク 1）。
これは日をまたがないと確認できない。

- [ ] **翌日**開いて、記録が残っている
- [ ] 翌日、「今日」が **0分**にリセットされ、「累計」は減っていない
- [ ] 翌日学習すると「連続」が **2日**になる
- [ ] 2 日空けてから開くと、連続が 1 から数え直される。
      **そのとき責める文言が出ていない**（「おかえり。また一緒に葉を育てよう。」）
- [ ] **1 週間後**に開いて、記録が残っている（ここが ADR-0001 の本丸）

---

## 終わったら: 記録を戻す

架空の記録を消して、本物の記録に戻す。

1. 植物ビュー →「記録の持ち出し」→「取り込む」
2. 最初に書き出した `monmana-YYYYMMDD.json` を選ぶ
3. 「n件の記録を取り込みました。」と出る

- [ ] 取り込み後、**元の記録に戻っている**
- [ ] 試しに関係ないファイル（写真など）を取り込もうとすると、
      **取り込まれず「いまの記録はそのままです」と出る**

## 見つけたら教えてほしいこと

うまくいかなかった項目は、**どの段階のどの行か**を教えてもらえれば直せる。

特に知りたいのは以下。

| 種類 | 例 |
| --- | --- |
| **音** | 鳴らない / うるさい / 素っ気ない / 気づかない |
| **タイマーのずれ** | 画面を離れて戻ったら残り時間が違う |
| **記録の消失** | 開き直したら消えていた |
| **文言** | 責められている・急かされていると感じた |
| **見た目** | 崩れている / はみ出している / 小さすぎる |
| **モンステラ** | 育った感じがしない / 葉の数が合わない |

**「なんとなく違う」でも構わない。** 特にモンステラの見え方と音は、
エージェント側では良し悪しを判断できない。
